# talentos-legal

Páginas legais do app **Talentos** (quiz bíblico, Hermes Digital), publicadas por GitHub Pages
em https://hermesdigitalbr-spec.github.io/talentos-legal/

- `/terms`, `/privacy`, `/support` (pt-BR) e `/en/terms`, `/en/privacy`, `/en/support` (inglês).
- O app aponta para `/terms` e `/privacy` — não renomear os arquivos.
- Para editar: altere o texto em `build.py` e rode `python3 build.py` (gera os `.html` com o CSS embutido).
